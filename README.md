# Faultline FC website concept

Independent concept by Luis Fausto. Not the official club website.

## Free GitHub Pages hosting
1. Create a public repository named faultline-fc-demo.
2. Upload index.html, crest.png, robots.txt and this README to its root (unzip first).
3. Open Settings > Pages.
4. Choose Deploy from a branch, main, / (root), then Save.
5. Use the live URL shown in Pages once deployment finishes.

No install or build command is required. Asset links work under a GitHub project subdirectory.
The demo intentionally uses noindex. The canonical points to the real club website.
Before official launch: confirm program details, replace demo notices, update social metadata for the final domain, remove noindex, and submit a sitemap.
